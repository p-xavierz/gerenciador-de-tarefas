# 📝 Gerenciador de Tarefas(Em andamento)

Aplicação web de gerenciamento de tarefas desenvolvida com **React.js**, como projeto de estudo e prática em desenvolvimento web.

O projeto tem como objetivo aplicar, na prática, conceitos fundamentais do React, como componentes, propriedades, estados, eventos, formulários e renderização dinâmica.

## 🚀 Sobre o projeto

O Gerenciador de Tarefas permite criar e visualizar tarefas, além de controlar o status de conclusão das atividades.

A aplicação está sendo desenvolvida de forma incremental como parte do meu aprendizado em **Análise e Desenvolvimento de Sistemas**.

## 🛠️ Tecnologias

- React.js
- JavaScript
- Tailwind CSS
- React Router DOM
- Lucide React
- Vite
- Git
- GitHub
